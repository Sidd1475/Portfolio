# Siddharth Mishra — AI Engineering Portfolio

A modern, high-performance portfolio showcasing engineered AI systems, agentic state-graph workflows, retrieval-augmented generation (RAG) pipelines, predictive machine learning models, and full-stack software architectures.

## ✨ Systems & Case Studies

- **CareerLens** — *AI Resume Analysis Platform*
  - 4-stage directed acyclic graph (DAG) orchestrated with LangGraph and FastAPI.
  - Concurrent parsing of resume and job description, deterministic scoring, and grounded Gemini LLM feedback.
- **AgriInsight** — *Crop Yield Intelligence System*
  - District-level agricultural yield forecasting trained on 340,000+ national records using scikit-learn and Random Forest ($R^2 \approx 0.80$).
  - Target encoding, compact ~24.5 MB deployment footprint, and explainable feature importances in Streamlit.
- **YT GPT** — *RAG-Based YouTube Chatbot*
  - 8-stage retrieval-augmented generation workflow with FAISS dense vector search and Sentence Transformers.
  - Grounded question-answering with timestamp citations and conversational context memory.
- **NeuroScan AI** — *Brain Tumor Classification using Deep Learning*
  - Multi-class convolutional neural network classifying Glioma, Meningioma, Pituitary, and Healthy MRI scans.
  - Image preprocessing, bilateral filtering, data augmentation, and diagnostic probability breakdowns.
- **Sukoon AI** — *AI Mental Wellness & Emotional Support Companion*
  - Empathetic conversational companion supporting real-time voice and chat, mood analytics, and habit streaks.
  - "Ghost Mode" anonymous peer spaces and deterministic crisis escalation safety guardrails.
  - [Live Application](https://sukoon-ai.vercel.app/)

## 🚀 Getting Started

### Prerequisites
- Node.js 18.x or higher
- npm, pnpm, or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/Sidd1475/Portfolio.git
cd Portfolio

# Install dependencies
npm install

# Run the development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
